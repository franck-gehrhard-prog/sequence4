# BeThom - Portfolio en ligne

**BeThom** est le site vitrine et portfolio de Thomas, graphiste et codeur. Ce site moderne, performant et entièrement responsive a pour but de présenter ses compétences, ses articles de blog, ses travaux de design et d'illustration, ainsi que de permettre une prise de contact directe.

## 🚀 Fonctionnalités

*   **Section Hero / Accueil :** Présentation textuelle avec bouton de téléchargement de CV intégré.
*   **Blog :** Grille d'articles récents mettant en avant des compétences techniques (Figma, Design Systems).
*   **Portfolio (Mes Travaux) :** Présentation structurée de projets (UI/UX Dashboard, Illustrations, Typographie) avec visuels.
*   **Section Contact :** Formulaire de contact complet et informations professionnelles.
*   **Design Responsive :** Menu mobile interactif et mise en page adaptée (via CSS Grid et Flexbox) pour une navigation fluide sur smartphones, tablettes et ordinateurs.

## 🛠️ Technologies utilisées

*   **HTML5** : Structuration sémantique du contenu.
*   **CSS3** : Styles personnalisés, mise en page moderne (Grid & Flexbox) et Media Queries pour le responsive.
*   **Polices d'écriture** : Google Fonts ([Heebo](https://google.com)).

## 💻 Installation et aperçu local

Pour afficher et tester le projet sur votre machine locale :

1. **Cloner le dépôt** (ou télécharger les fichiers sources) :
   ```bash
   git clone https://github.com
   ```
2. **Naviguer dans le dossier du projet** :
   ```bash
   cd bethom-portfolio
   ```
3. **Ouvrir le site** :
   Ouvrez simplement le fichier `index.html` dans le navigateur de votre choix, ou utilisez une extension d'éditeur (comme *Live Server* sur VS Code) pour un rafraîchissement automatique.
